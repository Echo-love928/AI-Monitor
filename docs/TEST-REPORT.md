已检查 375、768、1440 px，页面没有横向溢出；亮色布局、手机导航与表单可用。实际操作新增范围、编辑表单、切换关键词/范围、暂停、恢复、状态/搜索/来源组合筛选、关注度排序、事件详情与 Escape 关闭。修改后重新检查构建版本；证据说明显示材料类型与读取限制。

请用户先验收：

1. 打开本地页面，确认亮色风格及手机/桌面布局。
2. 在“我的监控”编辑示例“AI 编程前沿”，或添加自己的关键词/范围；确认暂停、恢复和保存结果。
3. 在“最新信号”查看已核实与待核实内容，筛选后打开详情，核对来源、日期、判断理由与摘要/全文区别。
4. 在“运行记录”查看各来源和审核结果；关闭网页后重新打开，确认后台继续在线。

验收页中的示例范围当前已暂停，历史结果仍可查看；恢复或添加自己的规则后统一每 30 分钟执行。后台进程保持在线。正式邮件验收需未来配置 SMTP 与接收邮箱，再执行连接检查、测试邮件、实际新增事件通知及收件确认。网页版验收通过后，才继续 Agent Skills。
