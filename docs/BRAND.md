## 配色与使用

| 用途 | 色值 |
| --- | --- |
| 图形主体 | `#CF4820` |
| 信号点 | `#F3B565` |
| 字标 | `#533B2C` |
| 暖杏奶油背景 | `#FFF3E7` |

侧栏在桌面使用 40 像素图形，在手机使用 32 像素图形。保持 F 主体与信号点的相对位置，不单独拉伸、旋转或给标识增加光晕。页面标题、加载页、侧栏入口、邮件品牌文案和项目说明使用 FirstCue。

监控数据、规则、存储文件和邮件 Message-ID 保持原有标识，确保已有任务可以继续执行。
