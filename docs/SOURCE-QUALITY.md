## 实施结果

用户追加确认：允许验证搜狗；尝试百度、Bilibili 和微博。B站、微博先通过搜索引擎发现公开链接，读不到原始材料时保留待核实，不增加登录、Cookie 或新 Key。

新增 `server/quality.ts` 和 `server/search.ts`。采集时保存回复、会话、展开链接及内容类型，搜索排除回复与纯转发，后端二次分类；官方及原作者补充仅进入对应父帖或会话。未知类型不视作原创；补齐真实类型与链接后可恢复审核资格。新过滤策略独立保存 X 检查点，终页 null 游标兼容，非终页缺游标仍报错并保留窗口。

先在预算内轮转发现，再在同一十次搜索上限内预留最多两次补证。X 原帖与引用原文尽量同批送审，总分析材料不超过设置上限，X 候选最多十条。获取原文后重新检查日期，旧文章不因搜索摘要无日期而成为新事件。重新核实只复用已保存材料，全程不发起新采集或原文请求。

URL 去重保留原始材料和发现渠道，搜索跳转读取受控字面 URL，不执行 JavaScript；所有目标仍由现有公共 HTTP 客户端校验。共享平台只信任允许的发布者命名空间；多家媒体引用同一已知官方 URL 不计为独立来源。独立性还依赖文本相似度和 AI 对原文的判断，不承诺仅靠域名即可识别所有转载。
