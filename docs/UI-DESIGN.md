# FirstCue 前端设计

品牌名称与 F 形标识采用用户确认的 FirstCue 方案；配色、资源与验收见 [品牌规范](BRAND.md)。

设计目标：尽快发现热点，查看可信证据，整理有价值的分享内容。

依据 ui-ux-pro-max 的 monitoring dashboard / analytics 设计系统与 React 性能指南，采用紧凑仪表台布局、清晰状态和轻量交互。按用户要求将默认冷色调整为暖白、暖杏奶油、橙红、琥珀色；正文使用系统字体，避免外部字体请求。

## 视觉与交互

- 暖白画布，暖杏奶油导航与首页主视觉；深暖棕文字、浅杏选中底色与橙铜色高亮。
- 紧凑首页头图，四个真实状态概览，信号列表保持主视觉重心。
- 关注度大于等于 70 的已核实事件显示“高关注”，分值是业务关注度，不冒充传播量或实时增速。
- 摘要复制包含核实状态、发生时间（可用时）、发现时间和去重后的来源链接；待核实内容保留明确标识。
- 列表每次展示 12 条，筛选后重置；查询和排序作用于全部已加载事件。
- 所有页面共享语义颜色、按钮、输入框、焦点和反馈；移动导航保留文字。

## Aceternity UI

通过 Context7 查询官方最新安装与用法，并从官方 registry 获取源码：

- [Bento Grid](https://ui.aceternity.com/components/bento-grid)：用于状态概览；保留官方组件结构，使用主题 CSS 调整密度。
- [Grid & Dot Backgrounds](https://ui.aceternity.com/components/grid-and-dot-backgrounds)：2026-10-15 经 Context7 重新核对官方 GridSmallBackgroundDemo，将细网格与渐隐遮罩提取为无依赖装饰层，搭配奶油色主视觉。
- [Background Beams](https://ui.aceternity.com/components/background-beams)：仅用于首页装饰，按需加载 Motion；路径从 50 条减为 8 条，随机无限动画调整为约 3 秒的一次入场，支持 prefers-reduced-motion。

采用 Tailwind CSS v4 的 Vite 集成，仅导入主题和工具类，不使用全局 preflight，避免影响现有表单和原生 dialog。

装饰组件通过动态导入独立加载；资源加载失败时显示完整静态界面。按钮复制成功后显示短暂的“已复制摘要”，原生弹窗内也能得到明确反馈。

## 验收

类型检查与生产构建；既有业务测试；桌面与手机布局；导航、筛选、详情、复制、表单和减弱动效。UI 验收使用隔离测试数据，不触发真实付费采集或发送邮件。

2026-10-14 验收结果：

- `npm run build` 与 `git diff --check` 通过。
- 23 项既有业务测试通过。
- 68 项浏览器检查通过，未发现 JavaScript 运行错误；覆盖 1440、1024、768、390、375、320 像素宽度与 844 × 390 横屏，六个页面均无横向溢出。
- 核实状态/来源/搜索筛选、关注度排序、分页、详情与 Escape 关闭、监控表单、来源切换、复制内容和剪贴板降级正常。
- 减弱动效为静态光束；装饰资源加载失败不影响主要界面。
- 现有本地 API 数据的只读加载验收通过。

生产主 JavaScript 约 94.6 kB gzip（原版约 82.5 kB），光束模块独立约 44.0 kB gzip，CSS 约 13.3 kB gzip。新增视觉组件不请求外部字体、图片或第三方运行时服务。

## 2026-10-15 暖杏奶油配色

用户确认采用暖杏奶油，并要求截图中的首页主视觉同步改色。侧栏底色 `#FFF3E7`、正文 `#533B2C`、选中底色 `#FFDCC0`、选中文字 `#A93213`。首页使用同色系浅渐变、深色文字与橙红主操作；来源路径、来源卡片、核验中心全部适配浅色。

Background Beams 保持一次短入场、按需加载和减弱动效支持；新增 GridBackground 使用官方静态 CSS 网格与遮罩方式，不增加依赖或持续动画。

本次 `npm run build`、`git diff --check` 和 68 项既有浏览器界面检查通过，未发现运行错误。实际本地数据加载与桌面/手机截图复核正常。侧栏正文、次要文字与选中菜单的对比分别约为 9.47、5.10、5.15；主按钮白字对比约为 4.56。

当前生产主 JavaScript 约 94.8 kB gzip，光束模块仍独立约 44.0 kB gzip，CSS 约 13.6 kB gzip。
